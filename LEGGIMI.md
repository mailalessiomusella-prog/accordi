# Quaderno Accordi: pubblicazione su GitHub Pages

Cartella pronta da caricare così com'è. Contenuto:

- `index.html`: l'app (tutto incorporato)
- `manifest.webmanifest`: dati per l'installazione come app
- `sw.js`: avvio offline dopo la prima apertura
- `icons/`: icone dell'app
- `.nojekyll`: impedisce a GitHub di rielaborare i file

I file vanno caricati nella radice del repository, non dentro un'altra cartella.
